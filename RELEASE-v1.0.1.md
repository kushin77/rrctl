# rrctl v1.0.1 - Release artifacts (SBOM & Signatures)

This is a small companion release that contains supply-chain artifacts produced by the automated CI workflow:

- SPDX SBOM (syft): rrctl-open-source-enterprise.spdx.json
- Release archive: rrctl-open-source-enterprise.tar.gz
- Checksums: rrctl-open-source-enterprise.tar.gz.sha256 and rrctl-open-source-enterprise.tar.gz.md5
- Cosign signature: rrctl-open-source-enterprise.tar.gz.sig.b64

These artifacts were generated by the GitHub Actions workflow `SBOM & Keyless Signing` and have been attached to the release assets. Use the SBOM to inspect included packages and licenses. Use the checksums and cosign signature to verify integrity and provenance. Note: the cosign signature included here was created as an ephemeral/demo signature; for production use we recommend KMS-backed signing or an OIDC + Rekor-anchored keyless flow.

Release artifacts were uploaded on December 5, 2025.

Links:
- Release (v1.0.1): https://github.com/kushin77/rrctl/releases/tag/v1.0.1

Verification examples:

```bash
# verify checksum (sha256)
sha256sum -c <(echo "<SHA256>  rrctl-open-source-enterprise.tar.gz")

# verify cosign signature (insecure without Rekor anchoring)
cosign verify-blob --key cosign.pub --signature rrctl-open-source-enterprise.tar.gz.sig.b64 rrctl-open-source-enterprise.tar.gz --insecure-ignore-tlog=true
```
